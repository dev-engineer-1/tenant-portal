# NestIQ: Transforming Traditional Companies into AI-Native Organizations

NestIQ is an innovative platform designed to track, measure, and adapt human capital in traditional companies, enabling them to seamlessly transition into AI-native organizations.

## Problem Statement

In today's rapidly evolving technological landscape, traditional companies face challenges in adopting AI technologies effectively. NestIQ addresses this gap by providing tools to measure and enhance human adaptability to AI, ensuring a smooth transition and sustainable growth.

## Key Features

- **Human Capital Tracking**: Monitor and analyze employee engagement and adaptability to AI tools.
- **AI Readiness Assessment**: Evaluate organizational readiness for AI integration.
- **Personalized Learning Paths**: Tailor AI learning modules to individual employee needs.
- **Performance Metrics**: Real-time dashboards to track progress and impact of AI adoption.
- **Integration with Existing Systems**: Seamlessly integrates with current HR and IT systems.

## Tech Stack

- **Backend**: Node.js, NestJS
- **Frontend**: React, TypeScript
- **Database**: PostgreSQL
- **AI/ML**: Python, TensorFlow
- **Cloud Services**: AWS

## Getting Started

To set up NestIQ locally, follow these steps:

1. **Clone the Repository**
   ```bash
   git clone https://github.com/yourusername/nestiq.git
   cd nestiq
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Configure Environment Variables**
   - Create a `.env` file in the root directory.
   - Add necessary environment variables as per `.env.example`.

4. **Run the Application**
   ```bash
   npm run start
   ```

5. **Access the Application**
   - Open your browser and navigate to `http://localhost:3000`.
